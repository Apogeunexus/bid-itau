- `scripts/servir-out.mjs` exporta `servir({raiz}) → {url, fechar}`.
- `scripts/navegador.mjs` exporta `abrirNavegador({largura, altura, ...})` que devolve **o
  `cdp` diretamente**, não um objeto que o contenha.
- O método de navegação é **`cdp.navegar(url)`**. Há também `cdp.recarregar()`,
  `cdp.assentar()`, `cdp.avaliar(expressao)`, `cdp.capturar()` e `cdp.encerrar()`.
- O console acumulado está em **`cdp.consola`**, uma lista de `{nivel, texto}`.

  um seletor CSS. Há também `cdp.clicarEEsperarUrl(seletorJs, predicado, rotulo)`.
- `PRELUDIO` e `naPagina(corpo)` embrulham o código com `visivel`, `todos` e `visiveis`.
- **`visiveis()` falha sobre SVG** — `offsetParent` é nulo em elemento SVG. Meça pino, mapa e
  qualquer coisa dentro de `<svg>` por `getBoundingClientRect()` e por atributo.
- **Não existe domínio `Network.*`.** Requisição externa se prova por
  `performance.getEntriesByType('resource')` de dentro da página, filtrando por origem.
- `cdp.capturar()` devolve PNG em base64. Escreva foto **só** quando `DIR_CAPTURAS` estiver
  definida, e **nunca dentro do repositório**.
- `CHROME_BIN` apontando para binário inexistente tem de derrubar a suíte com mensagem nomeada,
  sem cair no Chrome do sistema — o comportamento já existe em `navegador.mjs`; exercite-o.

**Mais três coisas que custaram tempo nesta obra:**

- **Atributo que só existe durante uma interação mede 0 no HTML exportado.** Conte-o no
  documento esperando zero, documente que o zero é de propósito, e meça o valor real no DOM
  vivo **depois de dirigir o gesto**.
- **Ao grepar a fonte, tire os comentários antes.** Vale para `--ic-*`, para `"use client"` e
  para qualquer varredura de proibição — `verificar-fase4.mjs` já tem o ajudante `fonte()`
  fazendo isso, e imprime as duas contagens, em código e em prosa. Repita o padrão.
- **Ao contar atributo no HTML exportado, case com a forma `data-{atributo}="`**, nunca com o
  nome solto, ou o payload RSC infla a contagem.
- **Comparação de data por string entre `DD.MM.AAAA` e ISO está quebrada.** Converta a número.
