Os oito arquivos do cabeçalho, e nada além. Em particular:

  nova vai para `src/estilos/{nome}.css` **e** ganha uma linha de `@import` em `globals.css`.

  Se este plano precisar de capacidade nova em algum deles, **pare e relate** em vez de

<disco_e_espelho>
## O risco vivo: iCloud com o volume a 96%

O projeto está em iCloud Drive num volume a 96% e o macOS já despejou arquivos no meio de uma
execução: `stat` reporta tamanho, a leitura devolve zero byte. Isso já destruiu de forma
permanente uma folha de estilo que foi commitada depois do despejo. Protocolo obrigatório:

1. **Antes de editar qualquer arquivo existente**, confirme que ele lê:
   `test -s <caminho> || echo VAZIO` — e para os que este plano altera,
   `wc -c src/app/globals.css` tem de bater com o tamanho do `git show HEAD:src/app/globals.css | wc -c`.
2. **Arquivo que leu zero byte se restaura do git**, nunca com `brctl download`:
   `git show HEAD:<caminho> > <caminho>`.
3. **Antes de commitar**, confira que nenhum arquivo do commit está vazio no índice:
   `git diff --cached --numstat` não pode mostrar remoção total inexplicada, e
   `git show --stat HEAD` depois do commit tem de listar as adições esperadas.
4. **Depois de cada commit**, empurre para o espelho: `git push espelho HEAD`.

## Para chegar ao Studio num Chrome headless

O Studio só existe na visão web (D-67) e a visão é estado da aplicação, não tamanho de janela.
O contexto de visão guarda a escolha em `localStorage` sob a chave `agenda-cultural:visao`,
como **string crua** — `web` ou `mobile`, sem JSON em volta. Numa checagem headless:

```
await cdp.navegar(url + '/studio/duplicatas/');
await cdp.avaliar("localStorage.setItem('agenda-cultural:visao','web')");
await cdp.recarregar();
```

A alternativa legítima é clicar no botão «Web» do alternador. Não invente um terceiro caminho.

**A API real de `scripts/navegador.mjs`** — os planos da fase 3 presumiram outra e pagaram por
isso: `servir({raiz})` devolve `{url, fechar}`; `abrirNavegador()` devolve o `cdp` direto; o
método de navegação é `navegar`; o console acumulado está em `cdp.consola`; e `cdp.clicar`
recebe uma **expressão JavaScript que avalia para o elemento**, não um seletor CSS.
`Network.*` não é acessível de fora.
