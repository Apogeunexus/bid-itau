<disco_e_espelho>
## O risco vivo: iCloud com o volume a 96%

O macOS já despejou arquivos no meio de uma execução: `stat` reporta tamanho, a leitura devolve
zero byte. Isso destruiu de forma permanente uma folha de estilo commitada depois do despejo.

1. **Antes de editar**, confirme que o arquivo lê: `test -s <caminho> || echo VAZIO`. Para os
   quatro deste plano, compare `wc -c <caminho>` com `git show HEAD:<caminho> | wc -c`.
2. **Arquivo que leu zero byte se restaura do git**, nunca com `brctl download`:
   `git show HEAD:<caminho> > <caminho>`.
3. **Antes de commitar**, confira `git diff --cached --numstat` — remoção total inexplicada é
   despejo, não edição. Depois do commit, `git show --stat HEAD` tem de listar as adições.
4. **Depois de cada commit**: `git push espelho HEAD`.
</disco_e_espelho>

<como_medir_a_tela_do_studio>
## Para chegar ao Studio num Chrome headless

O Studio só existe na visão web (D-67). A visão é estado da aplicação e vive em `localStorage`
sob `agenda-cultural:visao`, como **string crua** (`web` ou `mobile`, sem JSON em volta):

```
await cdp.navegar(url + '/studio/duplicatas/');
await cdp.avaliar("localStorage.setItem('agenda-cultural:visao','web')");
await cdp.recarregar();
```

**API real de `scripts/navegador.mjs`:** `servir({raiz})` → `{url, fechar}`; `abrirNavegador()`
devolve o `cdp` direto; o método é `navegar`; o console está em `cdp.consola`; `cdp.clicar`
recebe uma **expressão JavaScript que avalia para o elemento**, não um seletor CSS.
`visiveis()` do prelúdio usa `offsetParent` e **não serve para SVG** — forma dentro de SVG se
mede pelo retângulo.
</como_medir_a_tela_do_studio>

**A fusão declara o que ela é, antes de acontecer.** Um bloco `data-reversivel` com quatro

1. a fusão é **reversível** — existe o caminho de volta e ele está nomeado na tela;
2. ela **preserva procedência** — os dois registros mantêm o seu `ic` ou `autorado`, e a
   procedência de cada lado continua visível depois da decisão;
3. **nada é apagado** — o registro secundário continua existindo e continua consultável;

Nenhuma aresta do grafo muda quando o botão é apertado — a decisão é registrada na sessão do
navegador e a tela diz isso. O que a tela demonstra é a **forma** da decisão e o que ela
produziria num sistema com backend. Declare também, no mesmo lugar, que `duplicata_de` ainda

**D-72 — nenhuma fusão acontece sozinha.** Ao lado das ações, a frase de que a decisão é humana
